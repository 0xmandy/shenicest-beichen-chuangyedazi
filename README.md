## 怎么改

主产物就是那一个 html，**直接改它**。改版脚本是历史记录，不是构建流程，别再往里加新脚本改文件。

改补贴内容走另一条路：改 `data/policy-subsidy/…补贴条款-结构化….json`，然后

```bash
python3 tools/shenicest-tool-补贴门槛标注.py        # 改了门槛才要跑，出 判定门槛 与 门槛依据
python3 tools/shenicest-tool-补贴年度细则标注.py    # 换年度时跑，出 年度细则；要先有 policy-raw/rules/ 那批语料
python3 tools/shenicest-tool-补贴条款校验.py        # 324 个校验点，不过就停
python3 tools/shenicest-tool-补贴库结构化.py        # 出 tools/subsidy-db.js
python3 tools/shenicest-tool-补贴条款出简洁版.py    # 顺手刷新人读版 md
```

再把 `tools/subsidy-db.js` 整块换掉 html 里 `const SUBSIDY_ITEMS = ...;` 那一段。校验脚本要读 `data/policy-raw/` 下的政府原文才能比对引文，那批语料不入库（18MB），重建：

```bash
python3 tools/shenicest-tool-政策原文抓取.py      # 89 条 URL 库正文
python3 tools/shenicest-tool-政策附件抓取.py      # 42 份规则类附件
python3 tools/shenicest-tool-原文库联网补齐.py    # 30 份原文库正文
python3 tools/shenicest-tool-年度申报细则抓取.py  # 26 份年度征集通知 + 35 份附件，办理地点在这批里
```

第四个脚本翻两个栏目：朝阳区政务公开的部门文件（27 页，回溯到 2002 年）和公示公告（50 页，回溯到 2026-03）。它自带体检，有任何一条正文或附件失败就非 0 退出并打印失败清单，别拿「跑完了」当「抓全了」。已知有一条附件转文本失败，记在办理细则那份 md 的待核验缺口里。

改完这三步必须走，顺序不能反：

```bash
zsh tools/shenicest-tool-语法自查.sh                   # node --check
zsh tools/shenicest-tool-v3改版-qa截图与溢出探针.sh      # 截图 + 横向溢出探针
python3 tools/shenicest-tool-档案可改行为自测.py .        # 档案改动的连带重算
```

前两步是排版，第三步是状态机。第三步单独存在的理由：档案字段改一下要牵动六七处渲染，漏掉哪一处截图上完全看不出来，只有断言逮得到。

自查脚本会把截图与 dump 落在 `qa-out/`（已进 `.gitignore`），并在最后打印每个状态的溢出结论。**冷启动页 `onboard` 那一条是已知项**：团队原始 demo 自带的 30px 溢出（探针报 `onboarding active`），被 `phone-shell` 的 `overflow:hidden` 兜住，截图上看不出来，不用修。它跟探针跑的时机有关，同一份文件连跑两次可能一次报一次不报，别拿「这次没报」当它修好了。其余 23 个状态任何时候都该是 `none`，出现非 `none` 就是新引入的，先拿改动前的版本跑同一个探针对比再动手。

需要 Chrome。不在默认位置就 `CYD_CHROME=/path/to/chrome` 指过去。

部署：

```bash
zsh tools/shenicest-tool-部署到cloudflare-pages.sh
```

wrangler 的 OAuth 令牌会过期，过期了在交互终端跑一次 `npx --yes wrangler@latest login`。

## 改之前先知道的四条纪律

这四条是这个项目的立身之本，破了一条整个「防幻觉」的说法就塌了。

1. **政策与金融的额度、期限、利率只能来自原文**。金融是命题方那张表，补贴是政府网站上的政策原文（本地留档在 `data/policy-raw/`，每条可回链）。原表写「根据企业实际情况不定」的，界面显示「以机构核定为准」，不折算、不估算、不换口径。67 个金融产品里只有 28 个写了具体额度、13 个写了利率口径，照实显示比装作全都有数据更有说服力。补贴那 44 条同理：原文没写申报截止日的，不替它编一个日期。

   **「措施写了这笔钱」跟「今年能报这笔钱」是两件事，界面上必须分开。** 朝阳区四份措施走年度制：措施定钱和条件，每年另发的实施方案才决定当年开哪几个方向。通用人工智能措施写了八条能拿的钱，2026 年度方案只列了其中两条，剩下六条今年报不了。这 23 条原来一律显示「看年度细则」，把「今年能报」和「今年根本没开」混在一起，用户照着去报会白跑。现在 `plan.st` 分 listed 与 notlisted 两种，notlisted 的收进折叠区并写明原因。判定入口只有 `subsidyWindow` 一处，卡片、排序、解锁对照条都从它取，别在别处另判一次。

   补贴卡上「最多能拿」那一格有个坑，踩过四次：**不许直接摆原文里的额度句**。首贷贴息原文的 2000 万是贷款合同上限、企业培育奖励的 1 亿是营收门槛、OPC 资源包的 1000 万是社区一年的兑付上限，这三个都不是企业能拿到手的钱，摆上去就是误导。所以真理文件里另开了手工写的 `卡面金额` 与 `金额排序值万元` 两个字段，口径是「一家企业按这一条最多能拿多少」，由校验脚本盯住两者不许对不上，**不许用正则覆盖**。

   **申请门槛同理，原文没写就不许补一个。** 朝阳区通用人工智能若干措施原文里没有支持对象条款，而它是钱最多的八条（最高 1 亿）。判定标成「原文没写门槛」，不替它安一个注册地要求。设了硬门槛的条目必须有 `门槛依据`，依据句由脚本从本地原文整句取，**不许手打**。界面上的措辞也守着边界：只验了硬门槛就写「门槛对上了」，不写「你符合」。
2. **办事流程里的数字**（审核工作日、开户时限、申领份数）必须来自检索到的官方口径，出处记在注释里，不许凭记忆写。早先那十三页的出处见 `tools/history/shenicest-tool-v4改版-t7-北京办事流程.py` 头部；后加的办证页出处写在 html 里 `TASK_PAGES['办证']` 上方的注释块，逐条底稿见 `data/task-license/…facts-二类增值电信业务经营许可证办理….md`。

   办证页里有一处专门按第三条纪律处理过，别顺手抹掉：申请材料里那句「三个负责人最近一个月的社保证明」只有广东省通信管理局的指南写了，北京市通信管理局没有把这一层公开发布出来。界面上照实说明它是外省口径，不冒充北京口径。
3. **检索不到就明说检索不到**，不编一条出来。判定不了的显式标「需人工核」，不吞掉。
4. **界面上不写元描述**。不出现「命题方」「这页的数据边界」「通用流程口径」「非政策原文」这类词，产品是给创业者用的，不是给评委看的证据展示。

另外三条工程约束：

- 单文件、纯静态、零外部依赖。不引 CDN、不引字体、不引图片链接。界面图标一律内联 SVG；「猜您需要」那 9 只卡皮巴拉是位图，也内联，走 base64 data URI，不走文件路径
- 换卡皮巴拉的做法：源图放 `assets/capy-icons/`，`cwebp -q 86 -alpha_q 90` 转 WebP 再 base64 塞进 html 里的 `CAPY_IMG`。144px 对应卡片上的 46px，够 3x 屏；九张一共约 56KB，转 base64 后约 75KB
- emoji 只保留管家老周的 🧑‍💼，其余全部内联 SVG
- 已经从 demo 里清掉的编造内容一条都不许回来（50 万补贴、网商银行生意贷、XX 创投、9 月对接会），清单见需求文档 4.5 节末尾

## 已知的坑

写在这里免得每个人再踩一遍，详细版在需求文档第五节。

- `.page-scroll` 是 flex 列容器，往里加带 `overflow:hidden` 的块必须配 `flex-shrink:0`，否则内容一长就被压成一条 2px 的线。短页面正常、长页面塌，肉眼很容易漏判
- macOS 上没有 `timeout` 命令，套上去直接 `exit 127`，还会把输出文件写成 0 字节，看着像页面炸了
- 无头 Chrome 截完图不退进程。QA 脚本已经改成轮询产物而不是 `wait`，但如果手动跑 Chrome，记得收尾 `pkill -f "user-data-dir=/tmp/cyd"`
- grep 溢出探针结果要滤掉探针自己的源码：`grep -o "QAOVERFLOW\[[^]]*\]" | grep -v "bad.length"`。写新探针的话更省事的做法是把标记字符串在运行时拼出来（`['CYD','RESULT'].join('')`），源码里就不存在完整标记，不用再滤
- `--dump-dom` 出来的 DOM 会把探针文本里的 `<<` `>>` 转义成 `&lt;&lt;` `&gt;&gt;`。按原文去 find 会一无所获，看着像探针没跑，其实跑完了还全是 PASS
- 整行删代码前先确认那行是不是完整语句。删跨行表达式的末行会留下悬空的 `+`，只有 `node --check` 逮得到

## 数据敏感度

金融库那 76 条是园区内部统计，含各家银行的门槛与利率口径。这份数据已经随 Pages 公网发布、可被搜索引擎抓取，所以放进这个私有仓库不构成新的暴露。要遮的话得给 Pages 项目加 Cloudflare Access，而不是只管仓库。
